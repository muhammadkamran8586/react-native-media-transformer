# Changelog

## 0.1.1

- Point the package homepage to the published documentation on mkamran.dev.
- Add documentation and npm links and an npm version badge to the README.
- No runtime or native API changes.

## 0.1.0

Initial version.

- Native MP4 export on Android and iOS with H.264 or HEVC, resizing, trimming, frame-rate limits, and AAC audio controls.
- Quality presets, progress reporting, cancellation, independent sessions, and sequential batches with abort support.
- Video metadata, JPEG thumbnails, and a React hook for compression state.
- Cached outputs with unique filenames by default, explicit overwrites, and temporary-file cleanup on failure or cancellation.
